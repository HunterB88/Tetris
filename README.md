# Tetris Game (Python + Turtle)

This is a simple Tetris game developed using Python's Turtle graphics library. It was created for my *Intro to Programming* course at the University of Minnesota.

## Features

- Classic Tetris mechanics
- Falling blocks with keyboard controls
- Line detection and clearing
- Score tracking
- Game over detection
- Object-oriented structure

## Controls

- **Left Arrow** – Move block left  
- **Right Arrow** – Move block right  
- **Down Arrow** – Move block down faster  
- **Spacebar** – Rotate block  

## Requirements

- Python 3.x  
- No external libraries required (uses built-in `turtle` module)

## Running the Game

```bash
python tetris.py
